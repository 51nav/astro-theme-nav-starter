# 重构计划 V2（需求 → 设计 → 任务列表）

## 1. 需求

### 1.1 背景问题
当前版本已可构建，但仍存在交互与架构问题：
- 侧边栏、分类区、标签页均在处理导航点击，职责分散，容易冲突。
- 首页内点击导航仍可能触发整页跳转，用户体验不够顺滑。
- Tab 组件缺少完整无障碍语义（仅有部分 `aria-selected`）。
- QRCode 库在页面初始阶段加载，非必要 JS 成本偏高。

### 1.2 目标
- 将导航行为统一收敛为一套事件机制。
- 在首页同页导航时实现无刷新滚动，跨页时再跳转。
- 补全 Tab 的可访问性语义与键盘可用性。
- 仅在用户点击“手机查看”后再动态加载二维码库。

### 1.3 非目标
- 不改动现有数据源结构（`src/data/config.json`）。
- 不新增外部 UI 框架。

---

## 2. 设计

### 2.1 导航行为统一
- 在 `Sidebar.astro` 中统一处理主菜单/子菜单点击：
  - 当前在首页：阻止默认跳转并平滑滚动到锚点。
  - 不在首页：跳转到首页锚点 URL。
- 移除 `Category.astro` 中对子菜单点击的重复监听。
- 移除 `TabPanel.astro` 中对侧边栏链接的监听，仅处理自身 Tab 按钮。

### 2.2 Tab 可访问性
- 增加 `role="tablist"`、`role="tab"`、`role="tabpanel"`。
- 增加 `id`/`aria-controls`/`aria-labelledby` 对应关系。
- 增加键盘方向键切换。

### 2.3 二维码性能优化
- 将 `QRCode` 改为点击时 `import('qrcode')` 动态加载。
- 保留现有 UI 与异常处理逻辑。

### 2.4 验证策略
- `npm run astro -- check`
- `npm run build`
- 页面截图验证（首页）
